# Qboltz — лендинг

Вёрстка секции «Concept UI» из Figma
([Qboltz, node 713:6687](https://www.figma.com/design/oJQYEBb5q5ecyGu5tN6wfW/Qboltz?node-id=713-6687)).

Запуск: любой статический сервер, например `npx serve .` или `npx http-server .`.

## Как устроено

- **Кадры 1–5** — один экран. Каждый шаг колеса, свайп или клавиша (↓, PageDown, пробел) плавно
  проявляет следующий кадр поверх текущего (кроссфейд по прозрачности, 0,9 с). Текст уходящего кадра
  гаснет за первую половину перехода, чтобы заголовки не накладывались. Один жест трекпада = один кадр.
  В кадре 1 фоном один раз проигрывается видео и останавливается на последнем кадре.
- **После кадра 5** страница скроллится обычным образом.
- **Кадры 6–8** — это три состояния одной секции. Пока она прилипает к экрану, карточки едут вместе со скроллом:
  меняются номер (01 → 03) и полоска прогресса. Клик по карточке прокручивает к ней.
- **Ховер на кнопках** (как в референсе Wedge): буквы по очереди, слева направо, гаснут и загораются.
  Эффект получает любой элемент с атрибутом `data-hover-text`.
- **Размеры** — в пикселях макета. Контент вписан в артборд 1440×820 с коэффициентом `--k = min(vw/1440, vh/820)`,
  фоны заполняют экран с `--K = max(…)`. При окне 1440×820 вёрстка совпадает с Figma 1:1.

## Ассеты

```
assets/
  css/style.css            стили
  js/main.js               переходы, карусель, ховер
  fonts/                   Geist Mono 500 (latin)
  icons/                   SVG из Figma: логотипы, уголки кнопок, скобки тегов, рамка карточки, маркер «best decision»
  images/swoosh.jpg        фон кадров 2–3 (поворот и кроп заданы matrix() из imageTransform в Figma)
  images/fan.jpg           веер кадра 4
  images/spiral.jpg        спираль кадра 5
  images/glow-wave.svg     размытая волна в кадрах 6–8
  images/noise.png         эффект Noise из Figma (mono, #000 25%, size 0.5)
  images/hero-poster.jpg   первый кадр видео (постер)
  video/hero.webm|mp4      фоновое видео первого кадра
```

## Что важно знать

- **Clash Grotesk** подключается с CDN Fontshare (`api.fontshare.com`). Если нужен self-hosting,
  скачайте шрифт с fontshare.com, положите woff2 в `assets/fonts/` и замените `<link>` в `index.html` на `@font-face`.
- В макете нет описания для третьей карточки («The whole problem»). Временно стоит текст из кадра 5:
  «Every variable, every rule, every dependency in a single problem. Nothing trimmed to make it fit.»
- Ссылки «Talk to us» пока ведут к секции с карточками. Настоящий адрес (почта, форма) нужно подставить в `href`.
